# YouTube Poop

_**YTP is for creating YTPs using various effects known in the YTP Genre.**_
_**(YTP supports multisource)**_

## Effects

![Effects](/img/v4/ytp/effects.png)

* **Chorus**
  * Chorus Wobble Effect
* **Change Pitch**
  * Change Pitch to Random Value
* **Vibrato**
  * Pitch Weirdness Effect
* **Reverse**
  * Reverses Clip
* **Delay**
  * Delay Echo
* **Change Speed**
  * Stretches Video
* **Change Hue**
  * Changes Color
* **Rotate Hue**
  * Animated Changing Color
* **Black and White**
  * Mono Color
* **Negative**
  * Inverts Color
* **High-Frequency Repeat**
  * Repeats Clip rapidly
* **Random Tuning**
  * Random Generated Pattern of Pitches
* **Enlarge**
  * Upsizing Video Randomly
    ::: important
    *Also Increases Volume*
    :::
* **Sphericalization**
  * Fish Eye Effect
* **Mirroring**
  * Mirrors Clip
* **High Contrast**
  * Increases Contrast
    ::: important
    *Also Maxs Volume*
    :::
* **Oversaturation**
  * Max Contrast
    ::: important
    *Also does a pitch-up effect*
    :::
* **Thrice to Emphasize**
  * Up Pitch as it repeats in a sporadic motion.

## Parameters

* **Minimum Length**
  * Controls the Minimum Length for the Clip to Generate
* **Maximum Length**
  * Controls the Maximum Length for the Clip to Generate
* **Number of Clips**
  * The Value of Clips Generated
    ::: important
    *The max number of clips generated is 300*
    :::
