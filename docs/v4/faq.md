@en ::: details ### My MIDI File isn't working.
@zh ::: details ### 我的MIDI文件不能工作。
@en Make sure you have exported the MIDI file with a compatible program (e.g. FL Studio) and it has MIDI Channels/Tracks. A MIDI file that has no channels or tracks in it will not load or not correctly work with the script. If the MIDI is the MIDI file itself, try re-exporting the MIDI by re-importing it into the same program it was exported from and exporting it again.
@zh 确保您已使用兼容的程序（例如FL Studio）导出MIDI文件，并且该文件具有MIDI通道/音轨。没有通道或音轨的MIDI文件将无法加载或无法正确使用脚本。如果MIDI就是MIDI文件本身，请尝试将MIDI重新导入导出的程序中，然后再次导出。

@en If the MIDI file is from FL Studio. Make sure you go to [[Tools > Macros > Prepare for MIDI Export]], then `Export` as a `.mid` file.
@zh 如果MIDI文件来自于FL Studio。请确保你先进行了 [[工具 > 宏 > 准备进行MIDI导出]]，然后再 `导出` 成一个 `.mid` 文件。

@en If the MIDI file is from Reaper. When you're done with the project, go to `Export Project MIDI`, select your `input` tracks to **`Entire Project`** and **`All Tracks`**. Set the `output` to **`Multitrack MIDI file (type 1)`** and hit [[OK]].
@zh 如果MIDI文件来自于Reaper，完成项目后，请转到 `导出项目MIDI`，选择 `输入` 轨道为 **`整个工程`** 和 **`全部轨道`**。将 `输出` 设置为 **`多轨道MIDI文件（MIDI1格式）`**，然后单击 [[确定]]。

@en If it still doesn't work, it may likely be [`Velocity Error!`](#velocity-error) or [`Could not load file or assembly "NAudio"`](#could-not-load-file-or-assembly-naudio-operation-is-not-supported).
@zh 如果它还是不能工作，这很有可能是 [`力度错误！`](#力度错误) 或 [`无法加载文件或程序集“NAudio”`](#无法加载文件或程序集-naudio-操作不支持)。
:::

@en *Note from posterity (editor):* This error first occurred in the v0.1 version of the script. On line 17 and onwards of the script is the following code:
@zh *后人（编者）的注解：*该错误最早发生于v0.1版本的脚本中，在脚本的第17行及之后为以下代码：

```CSharp
public Dictionary<string, int> pitchMap = new Dictionary<string, int> {
    { "C0", 0 },
    { "C#0", 1 },
    // ...
    { "A#8", 106 },

@en Notice that there are no parentheses after code `new Dictionary<string, int>`. The standard syntax should be `new Dictionary<string, int>()`. The syntax feature that allows the omission of parentheses `()` for no-argument constructors in object creation expressions with collection initializers is supported starting from **C# 3.0** and **.NET Framework 3.5**.
@zh 注意到代码 `new Dictionary<string, int>` 处没有加括号，标准的写法应该是 `new Dictionary<string, int>()`。而在带有集合初始化器的对象创建表达式中，允许省略无参构造函数的括号 `()` 这一语法特性，是从 **C# 3.0** 和 **.NET Framework 3.5** 开始支持的。

@en When Microsoft introduced *LINQ*, it also introduced the "Object and Collection Initializers" syntax. It is clearly stated in the language specification of C# 3.0: **When using an initializer (braces `{}`), if a parameterless constructor is called, the parentheses `()` after the type name can be omitted.**
@zh 微软在引入LINQ的同时推出了“对象和集合初始化器”（Object and Collection Initializers）语法。在 C# 3.0 的语言规范中明确规定：**当使用初始化器（大括号 `{}`）时，如果调用的是无参数构造函数，则类型名后面的圆括号 `()` 是可以省略的。**

@en This is enough to show that Vegas Pro 12 should use C# 1.0/2.0 and .NET Framework 1.0/2.0 as the scripting framework.
@zh 这足以说明Vegas Pro 12应该采用了C# 1.0/2.0和.NET Framework 1.0/2.0作为脚本框架。

@en :::: details ### Mapping Velocity Explanation

@en * Mapping Velocity will generate events in the timeline where the opacity (for video) or volume (for audio) corresponds directly to the velocity value of each MIDI note, based on the range you set in the script.
@zh * 映射力度将在时间轴中生成事件，其中不透明度（对于视频）或音量（对于音频）根据你在脚本中设置的范围直接对应于每个MIDI音符的力度值。
@en * The standard MIDI velocity range is 0 – 127.
@zh * 标准MIDI力度范围为0 ~ 127。
@en   You can set a custom velocity range and map it to your desired opacity or volume range.
@zh   你可以设置自定义力度范围并将其映射到你所需的不透明度或音量范围。
@en ::: tip Example

@en If you set the velocity range to 64 – 127 and the opacity/volume range to 50% – 100%:
@zh 如果将力度范围设置为64 ~ 127，并将不透明度/音量范围设置为50% ~ 100%：
@en * Notes with velocity 64 (Half velocity in FL Studio or Reaper) will generate at 50% opacity/volume. And notes with velocity 127 will generate at 100% opacity/volume.
@zh * 力度为64（FL Studio或 Reaper中的表示一半力度）的音符将以50%的不透明度/音量生成。力度为127的音符将以100%不透明度/音量生成。
:::
::: important
@en Mapping Velocity does not ignore notes outside your set range.
@zh 映射力度不会忽略设定范围之外的音符。
@en * If a note's velocity is lower than your minimum setting, the generated event will be muted (0% volume / fully transparent).
@zh * 如果音符的力度低于最小值设置，生成的事件将被静音（0%音量/完全透明）。
