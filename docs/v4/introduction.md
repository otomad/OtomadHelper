@en # Welcome to Otomad Helper Documentation!
@zh # 欢迎来到Otomad Helper说明文档！

@en **Otomad Helper** is a YTPMV/otoMAD/YTP script for Vegas Pro that enables Vegas to accept MIDI sequence files as input and automatically generate YTPMV tracks.
@zh **音MAD助手**是Vegas Pro的音MAD/YTPMV/YTP脚本，旨在使Vegas能够接受MIDI序列文件作为输入并自动生成音MAD的轨道。

@en ![Overview](/img/v4/overview.png){.shadow-less}
@zh ![概览](/img/v4/overview_zh-CN.png){.shadow-less}

@en The script is redeveloped based on the original author [@Chaosinism](https://github.com/Chaosinism)’s open source code and uses the NAudio library.
@zh 本脚本基于原作者 [@Chaosinism](https://github.com/Chaosinism) 的开源代码二次开发，此外使用了NAudio库。

@en Check out the [usage](./usage.md) section for further information, including how to [install](./installation.md) the script.
@zh 查看[用法](./usage.md)部分以了解更多信息，包括如何[安装](./installation.md)该脚本。

@en _This documentation was originally written by [@Evauation](https://github.com/Evauation)._
@zh _本说明文档最初由 [@Evauation](https://github.com/Evauation) 编写。_

@en ## Sub-Features
@zh ## 子功能
