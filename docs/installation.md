@en # Installation
@zh # 安装

@en 1. <Button href="https://github.com/otomad/OtomadHelper/releases/latest"><b>Download</b> the latest version of this extension</Button>
@zh 1. <Button href="https://github.com/otomad/OtomadHelper/releases/latest"><b>下载</b>最新版扩展程序</Button>
@en 2. Unzip **ALL** the files in the compressed file you’ve just downloaded to the “Application Extensions” folder.
@zh 2. 将你刚刚下载到的压缩文件中的**所有**文件解压缩到“Application Extensions”文件夹中。
@en     If this folder does not exist, please create a new one.
@zh    如果该文件夹不存在，请新建。
   ::: code-group
@en    ```[Path]
@zh    ```[路径]
   C:\ProgramData\VEGAS Pro\Application Extensions
   ```
   :::
@en 3. Make sure that the DLL file is not locked.
@zh 3. 请确保 DLL 文件未锁定。

@en ::: tip Specific steps
@zh ::: tip 具体步骤
@en 1. Enter folder `C:\ProgramData\VEGAS Pro\Application Extensions`.
@zh 1. 进入 `C:\ProgramData\VEGAS Pro\Application Extensions` 文件夹。
@en 2. Right-click the “Otomad Helper.dll” file and select Properties.
@zh 2. 右键单击 “Otomad Helper.dll” 文件，然后选择“属性”。
@en 3. If you see the “Unblock” button (Windows 7/8.x) or checkbox (Windows 10+), click or check it.
@zh 3. 如果你看到了“解除锁定”按钮 (Windows 7/8.x) 或复选框 (Windows 10+)，请单击或选中它。
@en 4. Click OK button and you’re done.
@zh 4. 单击“确定”按钮即可。
:::

@en 4. Open Vegas Pro to launch it. Select menu [[View > Extension > Otomad Helper]] to open.
@zh 4. 打开 Vegas Pro 来启动。选择菜单 [[视图 > 扩展 > Otomad Helper]] 打开。
